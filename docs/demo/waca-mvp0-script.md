# WACA MVP-0 60-Second Demo Script

## 0–10 秒：用户痛点

说明科研新人只有“我想复现 WACA”这样的模糊目标，不知道第一步做什么，也不知道怎样才算完成。

## 10–20 秒：输入目标

输入：
“我想复现 WACA 论文，但不知道从哪里开始。”

点击：
“载入 WACA 演示案例”。

## 20–35 秒：目标收敛

展示系统生成的具体 objective：

实现并验证 WACA-SE 两阶段注意力模块，而不是直接要求完成整篇论文复现。

指出预计时间、协作模式和当前 Boss 状态。

## 35–50 秒：验收与证据

展示三类状态：

- AC-1：通过
- AC-2：未通过
- AC-3：通过
- AC-4：待验证

重点说明：系统不会因为代码能够运行就宣布任务完成；Stage 2 使用错误输入时，Boss 只能处于 PARTIAL。

## 50–60 秒：结束画面

停留在验收标准和 Evidence Map 页面。

结束语：
“Boss 不替科研新人假装完成任务，而是把模糊目标变成能够验证、能够失败，也能够继续推进的科研过程。”
