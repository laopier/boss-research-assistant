**负责人：队长**

## 目标

形成不依赖代码实现的 WACA 演示真值与 MVP-0 验收记录，让 Web 和 AI 两端使用同一套语义。

## 文件边界

- `docs/demo/**`
- `docs/product/**`
- 不修改 `src/**`

## 工作项

- 确认 WACA 示例 objective、范围边界和三条验收标准。
- 确认 `PASS / FAIL / UNKNOWN / NOT_RUN` 的产品文案。
- 写一段 60 秒 MVP-0 演示脚本。
- 按 README 在一台未参与开发的电脑上完成启动验收并记录结果。

## 验收

- 演示脚本包含输入、点击、预期输出和结束画面。
- WACA 产品文案没有需要 Web 或 AI 各自猜测的字段。
- 保存新电脑启动所用环境、耗时和问题记录。
